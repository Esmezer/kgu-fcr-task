# CAT-01

Мы начинаем разбираться с **асинхронным кодом и загрузкой данных**.

Задача — сделать **простое приложение, которое по нажатию кнопки показывает IP-адрес пользователя**. Данные нужно получить из **бесплатного публичного API** асинхронно (`fetch` + `async/await`).

В качестве примера и шаблона используется **ipify** — сервис, который возвращает IP-адрес клиента. На практике мы разберём его вместе.

> Многие публичные API недоступны из браузера или требуют VPN. Поэтому в качестве примера берём **ipify**: он отдаёт простой JSON и работает без ключа.

## Требования к окружению

Версия ноды, которую я использую — **v24.21.0**.

Проверьте вашу версию:

```bash
node -v
```

Установите нужную версию:

```bash
nvm install 24.21.0
```

## Что нужно сделать

> В ветке `task/CAT-01-demo` лежит готовый шаблон приложения: кнопка **«Показать мой IP»** и область для результата. Сейчас по нажатию кнопки выводится **ошибка**, потому что API ещё не подключён — это и есть ваша задача. Зависимости уже описаны в `package.json` — просто установите их командой `npm install` и добавьте загрузку данных. Если делаете всё с нуля — выполняйте шаги ниже.

1. Инициализировать проект через npm:

   ```bash
   npm init
   ```

2. Установить `typescript` и `esbuild`:

   ```bash
   npm install --save-dev typescript esbuild
   ```

3. Инициализировать и настроить `tsconfig.json` (не забудьте про `rootDir`, `outDir` и режим модулей).

4. Добавить в `package.json` скрипты сборки и разработки. Собирать будем через **esbuild**:

   ```json
   {
     "scripts": {
       "build": "esbuild src/index.ts --bundle --outfile=dist/index.js --format=esm",
       "dev": "esbuild src/index.ts --bundle --outfile=dist/index.js --format=esm --watch",
       "typecheck": "tsc --noEmit"
     }
   }
   ```

5. Разобраться с API **ipify**. Запрос:

   ```bash
   curl "https://api.ipify.org?format=json"
   ```

   Ответ:

   ```json
   { "ip": "176.52.83.148" }
   ```

   Хотите другой API — берите из [списка публичных бесплатных API](https://github.com/public-apis/public-apis), но тогда учтите ограничения браузера и CORS.

6. Загрузить данные асинхронно (`fetch` + `async/await`) по клику на кнопку и показать результат в интерфейсе. Не выводите сырой JSON — соберите из данных хотя бы минимальный UI. Обработайте ошибку: если запрос не удался, покажите понятное сообщение.

7. Стили — **mobile-first**, про десктопные размеры можно не думать.

8. Весь код пишем на **TypeScript**. Подход «как в React»: компонент — это функция, которая возвращает строку с HTML. В `index.html` уже есть `<div id="app">`, а `src/index.ts` рендерит в него `App()`.

9. Собрать проект через esbuild и проверить результат в браузере.
